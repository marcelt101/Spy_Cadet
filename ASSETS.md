# Pictures needed

Everything in the game is currently drawn in code: the map, the avatars, the machines and the paper. The only places waiting for real pictures are the history cards and the Records Room. They show a labeled "Photo to come" frame until a file is added.

## How to add one

1. Save the picture as a **JPG, portrait (about 4:5), around 800 px tall**.
2. Put it in `game/img/people/` with the exact file name below. The game picks it up automatically.
3. Add a line to `game/img/CREDITS.md`: file name, what it shows, source link and license (public domain, or the exact Creative Commons license).

US Navy and US government photos from the period are usually public domain (NHHC, National Archives, NSA / National Cryptologic Museum). Please check each one.
